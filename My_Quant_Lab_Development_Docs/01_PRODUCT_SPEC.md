# 01 产品规格（PRD）

## 1. 用户画像

目标用户是不具备程序开发和量化金融专业背景、但希望利用 NAS 和 AI 研究美股、ETF、加密货币等资产的个人用户。

产品必须遵循“复杂度隐藏、结果透明、解释通俗”的设计：用户主要面对策略卡片、回测结果、模拟盘结果和信号解释，而不是面对代码。

## 2. 用户目标

### G1：发现策略
用户可以通过 GitHub 仓库或内置策略库发现 Price Action、趋势、动量、均值回归、突破等策略。

### G2：理解策略
AI 把代码、规则和量化指标翻译为普通语言，说明策略在寻找什么、什么条件会触发、什么行情不适用、主要风险是什么。

### G3：验证策略
所有策略进入统一回测引擎，用真实历史数据测试，并提供样本内/样本外、交易次数、收益、回撤、Profit Factor、Sharpe 等可复现结果。

### G4：模拟跟踪
用户可以创建虚拟账户，例如“PA Strategy”“Technical Strategy”“AI Combined”，分别运行信号并观察长期结果。

### G5：实时提醒
系统周期性扫描用户关注的证券/加密资产和策略，仅在策略条件真正成立时产生 BUY/SELL，其他情况为 WAIT/NO SIGNAL。

### G6：从结果学习
系统持续跟踪每个信号的后续结果，使用户能看到“过去生成的信号后来发生了什么”，避免只记录预测、不记录结果。

## 3. 核心用户流程

### 流程 A：导入 GitHub 策略

```text
输入仓库 URL
→ 获取仓库元数据
→ AI 分析项目
→ 识别策略逻辑
→ 发现指标/参数/交易规则
→ 风险和未来函数初检
→ 生成统一 DSL
→ 人工确认（可选）
→ 进入实验策略
```

### 流程 B：策略验证

```text
选择策略
选择资产
选择周期
选择历史区间
选择手续费/滑点
→ 运行回测
→ 查看交易列表和统计
→ OOS / Walk-forward
→ 保存不可变结果
```

### 流程 C：模拟盘

```text
选择经过验证的策略
→ 指定模拟资金
→ 系统实时产生信号
→ 按现实成交规则模拟成交
→ 记录持仓/资金/费用
→ 统计权益曲线
```

### 流程 D：实时信号

```text
OHLCV 更新
→ 指标/PA 特征计算
→ 策略规则执行
→ Portfolio Context 检查
→ 生成 BUY/SELL/WAIT
→ AI 解释
→ 通知
→ 追踪结果
```

## 4. 首页信息架构

建议首页不是“专业量化终端”，而是“个人研究仪表盘”：

1. 今日信号
2. 当前模拟账户
3. 我真实持仓的策略观察
4. 最近策略测试
5. 最近 GitHub 策略更新
6. 系统数据健康状态

## 5. 信号卡片

示例：

```text
NVDA
当前：WAIT
策略：PA Breakout V2
周期：1D

为什么：
价格刚刚突破前高，但策略要求的突破确认条件尚未全部满足。

策略历史统计：
样本数：386
历史胜率：53.4%
最大回撤：11.8%
Profit Factor：1.36

模拟盘：
最近 42 次信号
当前账户结果：+7.2%

我的组合：
NVDA 当前占比较高

下一观察条件：
若后续收盘满足确认条件，系统重新评估。
```

## 6. 三种信息必须分开

### A. 事实数据
例如收盘价、EMA20、ATR14、账户持仓权重。

### B. 统计结果
例如回测收益、最大回撤、交易次数。

### C. AI 解释
例如“当前更像震荡环境，因此突破策略更容易出现假突破”。

UI 不得把三者混成一个“AI 评分”。

## 7. 策略生命周期

```text
IMPORTED
→ NORMALIZED
→ VALIDATED
→ BACKTESTED
→ OOS_TESTED
→ PAPER_TRADING
→ REFERENCE_SIGNAL
→ DEGRADED / RETIRED
```

生命周期变更必须保留时间、原因、数据集和版本。

## 8. 策略状态说明

- Experimental：刚导入或刚生成。
- Validated：规则、数据和代码检查通过。
- Backtested：完成至少一个可复现历史回测。
- OOS Tested：完成样本外或 Walk-forward。
- Paper Trading：正在模拟盘观察。
- Reference Signal：可以用于正式的“信息提醒/研究参考”。
- Degraded：近期行为明显偏离验证期，暂时降低使用范围。
- Retired：停止使用，但保留全部历史数据。

“Reference Signal”不是盈利承诺，也不是经过保证的推荐。
